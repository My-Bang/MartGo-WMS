# MartGO

## 📌 프로젝트 개요
- WMS(창고 관리 시스템)의 프로세스 학습 및 이해
- Java와 MySQL 연동 경험 (JDBC 사용)
- MVC 패턴을 활용한 구조적 프로그래밍 경험 습득
- 협업 프로세스 및 Git 활용 경험 축적

## 📋 프로젝트 설명
**MartGO**는 창고 관리 시스템(WMS, Warehouse Management System)을 구축하여 재고 관리 및 출고, 입고, 임대 등 창고 프로세스를 관리하는 시스템입니다. 본 프로젝트는 Java와 MySQL을 사용하여 데이터베이스와의 연동을 구현하며, JDBC를 통해 데이터를 처리하고 저장합니다. 또한, MVC 패턴을 적용하여 코드의 유지보수성과 확장성을 고려한 구조적 프로그래밍을 목표로 했습니다.
이 프로젝트는 협업을 통해 Git을 활용한 버전 관리와 팀원 간 역할 분담을 기반으로 진행되었으며, 각 기능은 모듈화되어 구현되었습니다. 이를 통해 실제 창고 관리 시스템에 필요한 주요 기능들을 학습하고 구현할 수 있는 기회를 제공하며, 실무에서 활용할 수 있는 기술적인 경험을 쌓을 수 있습니다.

## 💡 느낀점 및 개선할 점
✅ 느낀점
WMS 프로세스 학습: 창고 관리 시스템의 전반적인 흐름을 이해하는 좋은 경험이었으며, 실무에서도 활용 가능한 개념을 배울 수 있었습니다.
Java & MySQL 연동: JDBC를 사용하여 데이터베이스와의 연동을 직접 경험하며 SQL을 사용하여 프로시저나 트리거의 작성 능력이 향상되었습니다.
MVC 패턴 적용: 구조적인 개발 방법론을 익히면서 코드의 유지보수성과 확장성을 고려하는 중요성을 깨달았습니다.
협업 경험: Git을 활용한 협업 과정을 통해 코드 리뷰와 브랜치 전략을 실전에서 경험할 수 있었습니다.
문제 해결 능력 향상: 프로젝트 진행 중 발생한 다양한 오류를 해결하면서 디버깅 능력을 키울 수 있었습니다.

🔄 개선할 점
예외 처리 강화: 현재는 예외 처리가 잘 이루어지지 않았지만, 더욱 세부적인 예외 상황을 정의할 필요가 있습니다.
UI/UX 개선: 콘솔 기반에서 벗어나 GUI를 활용한 직관적인 화면 구성으로 발전시킬 수 있습니다.
추가 기능 개발: 현재 구현된 WMS 기능 외에도 실사 재고 조회, 통계 대시보드, 자동 출고 시스템 등 더 발전된 기능을 추가할 수 있습니다.
